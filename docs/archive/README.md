# Archive — research and evidence, not specification

These files are the discovery material the front-desk API was designed from: site-visit
documents and spreadsheets from the first pilot hospital (`.docx`, `.xlsx`, `.pdf`, `.doc`,
`.png`), the earlier v0.1/v0.2 API contract and a front-desk mock-up (`.html`), 80 redacted
patient-call transcripts (`transcripts_redacted/`), an independent design review
(`review-fable/`), and the working notes that led to the current design (`*.md`). None of it is
normative: the specification is `docs/frontdesk-api/`. The contents are kept on disk but are
**not committed** (see `.gitignore`) because they contain patient conversations and real
hospital names, numbers and staff data; nothing here may be seeded into a database or used on a
live call. `Jayashree_Phone_Numbers_SAMPLE.xlsx` in particular is self-declared invented data.
